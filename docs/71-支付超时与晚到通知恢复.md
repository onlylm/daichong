# 支付超时与晚到通知恢复

## 状态规则

- 未生成支付宝交易的订单超过付款窗口后，Worker 直接标记为 `expired`，不再无期限请求支付宝；
- 已生成支付宝付款码的订单到期后仍先查询支付宝，只有支付宝确认交易不存在时才标记 `expired`；
- 支付宝明确返回 `TRADE_CLOSED` 时标记 `closed`；
- `expired` 和 `closed` 都不再展示付款码。

## 晚到款

支付通知可能在本地超时处理之后到达。`expired` 不是资金事实终态：若之后收到应用、商户、订单、金额和签名全部校验通过的支付宝成功通知，系统必须将订单转为 `paid`，写入一次支付账本并发送一次 `order.paid`。重复通知不会重复记账。

`closed` 是支付宝明确关闭的渠道终态，不自动转为已支付；如外部记录出现冲突，应进入支付对账而不是人工改状态。

## 代理接入

代理商收到 `order.expired` 或 `order.closed` 后应立即关闭付款入口。Webhook 只用于加速状态同步，最终展示和履约前仍应签名查询订单；通知可能重复、延迟或乱序。
