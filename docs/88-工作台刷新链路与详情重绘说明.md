# 工作台刷新链路与详情重绘说明

## 总览刷新

工作台 `render` 传入的 `fresh` 与 `AbortSignal` 现在会继续传给：

- 平台总览的代理商、订单、经营数据和运营待办请求；
- 代理总览的订单、商品与公告请求。

手动点击“刷新总览”会绕过读取缓存。页面切换时旧请求会被取消，迟到响应不能覆盖当前页面。页面隐藏时暂停总览轮询，重新可见后再刷新；失败时平台总览保留最近一次成功值并标记为过期。

## 订单详情重绘

订单详情的变化指纹除支付状态、履约和退款外，还覆盖：

- 支付渠道、支付流水、实收金额和付款时间；
- 开票申请状态、版本、补差付款关联、发票号及审核结果；
- 退款、取消、重新提交、开票等动作权限；
- 可退金额、订单收款方式、履约阶段与更新时间。

因此后台轮询或手动刷新拿到新数据后，不会再出现“顶部提示已更新，但详情内容仍是旧值”的情况。

## 回归测试

测试覆盖强制刷新绕过缓存，以及开票变化、支付凭证变化、动作权限变化均触发不同的详情指纹。
