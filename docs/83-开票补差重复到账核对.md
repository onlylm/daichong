# 开票补差重复到账核对

## 规则

同一开票申请可以因支付意图过期而生成新的补差价支付单，但只能有一笔到账成为申请的正式付款关联。

## 到账处理

1. 首笔经支付宝验证成功的支付单成为正式付款，开票申请进入已提交。
2. 同申请的其他待支付意图立即本地关闭，停止继续展示为可付款。
3. 若已关闭或已过期的另一支付意图随后被支付宝确认实际到账，系统保留该支付单和支付宝流水。
4. 第二笔到账建立独立的 `invoice_payment_reconciliation` 财务核对记录，状态为待核对。
5. 开票申请始终保留首笔付款 ID 与首笔支付宝流水，第二笔不得覆盖。

支付宝明确返回 `TRADE_CLOSED` 的支付单仍保持终态，不能凭本地请求直接改记为到账。只有同申请因另一笔先到账而本地关闭的支付意图，之后收到已验签的成功事实时，才进入重复到账核对。

## 追溯

重复到账核对记录同时保存正式支付单、重复支付单、两笔支付宝流水和金额。该记录属于财务差异，不使用售后工单承载。
