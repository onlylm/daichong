# 管理员余额调整快照幂等说明

## 规则

管理员手动增加或减少代理商余额时，调整请求由以下内容共同确定：

- 代理商；
- 调整账户（采购余额或收益余额）；
- 增加或减少方向；
- 金额；
- 原因；
- 调整前确认的余额快照；
- 唯一调整编号。

服务在同一数据库事务内重新读取当前余额。只有当前余额与管理员页面提交的 `expectedBalance` 一致时才执行；否则提示刷新后重新确认。扣减后余额不得小于零。

## 本轮修复

历史实现已校验账户、方向、金额和原因，但同一调整编号重放时没有比较 `expectedBalance`。现已把原始余额快照纳入幂等内容：

- 完整内容一致的网络重试返回原分录，不重复增减；
- 相同编号但余额快照不同，返回 `adjustment_conflict`；
- 新编号但余额已变化，返回 `wallet_balance_changed`；
- 分录保留调整前金额、调整后金额、操作人、原因和时间，可从佣金/钱包流水追溯。

## 发布状态

本轮仅在本地重构分支完成和验证，未部署生产、未改动生产余额。
