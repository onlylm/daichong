# 代理操作审计分页

状态：已在本地重构分支实现并通过自动化测试，尚未部署生产。

## 改造内容

代理管理的“售后记录”页同时展示当前代理工单和操作审计。工单已经服务端分页，但旧操作审计接口仍会读取该代理全部审计记录、在应用层排序后截取 100 条，数据库读取量随历史增长。

现在 `/workspace/api/agents/{merchantId}/activity` 支持 `page` 和 `limit`，直接按租户、业务创建时间倒序分页。界面每页显示 20 条，并可用上一页、下一页继续追溯；工单页码和审计页码互相独立。

通用仓储分页类型增加 `audit` 记录支持：生产 SQLite 直接查询 `audit` 记录，内存仓储测试仍使用安全回退。现有按租户和创建时间组合索引可同时服务资金历史和操作审计。

## 权限与验证

接口继续要求 `agents.read`，并在查询前执行代理范围校验。返回内容与旧接口相同，仅增加分页元数据，不改变审计写入或记录内容。

SQLite 集成测试创建 13 条代理审计记录，验证第二页数据量、总数和页数正确，并确认实际调用仓储分页查询。全量类型检查、测试、构建与工作台脚本检查均须在提交前通过。

本轮没有连接或修改生产数据库，也没有部署服务器。
