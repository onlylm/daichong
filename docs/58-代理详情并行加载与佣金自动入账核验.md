# 代理详情并行加载与佣金自动入账核验

## 代理详情加载

- 代理商列表与当前代理摘要改为同时请求，不再先后等待两个网络往返。
- 代理概览只读取当前代理的钱包，不再读取全体代理钱包后在浏览器内筛选。
- 资金分区的钱包余额、核算单、当前流水和异常待入账收益改为一次并发加载，不再最后串行补查异常收益。
- 接口权限、资金事务和页面可见范围没有变化。

## 佣金入账口径

平台代收订单满足以下条件后，履约成功处理会同步触发幂等佣金入账：

1. 支付渠道已确认真实付款；
2. 上游明确返回履约成功；
3. 不是联调测试订单；
4. 没有待处理普通退款；
5. 该订单尚未入账。

入账写入唯一的 `wallet_credit` 和 `earning_release` 流水，同一成功回调重复到达不会重复增加余额。排队、处理中、结果未知、模拟履约和代理自收款订单不会提前释放平台代收佣金。

后台原“立即入账”区域改名为“待入账收益（系统异常）”，只在自动流程遗漏时用于幂等补登，不是正常日常操作。

## 自动验证

- 使用真实支付渠道标记和真实上游标记完成订单后，收益自动增加 25 元。
- 待核收益归零。
- 重放同一个上游成功事件后仍只有一条收益释放流水。
- 工作台脚本验证代理身份并行加载、当前代理钱包精确读取和资金请求并行。
