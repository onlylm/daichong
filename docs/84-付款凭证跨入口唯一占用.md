# 付款凭证跨入口唯一占用

## 业务约束

同一笔外部付款流水只能核销一项平台付款义务。提现确认和每日核算确认不是两个独立的流水号空间。

## 实现

- 提现与每日核算使用同一个付款凭证查询规则。
- 流水号去除首尾空格并转为小写后比较，避免大小写差异绕过防重。
- 两个入口都在写入钱包与业务状态的同一数据库事务内检查占用情况。
- SQLite 的 `BEGIN IMMEDIATE` 串行化并发写事务，防止两个入口同时通过检查后各自登记。
- 同一业务记录、相同内容的重放保持幂等；不同业务记录复用流水会被拒绝。

## 验证

- 先登记提现，再用同一流水确认核算：拒绝。
- 先登记核算，再用同一流水确认提现：拒绝。
- 大小写不同仍视为同一流水。
