# 订单开票与补差价流程

## 业务边界

- 代理商可直接在 Quefa 后台按已付款订单申请，无需开发自己的系统。
- 当前只受理企业发票，公司名称和纳税人识别号必须填写。
- 发票类目固定为“技术服务费”。
- 发票金额是代理商客户的实际成交金额，可以与 Quefa 供货价不同。
- 代理商在申请时单独支付发票金额的 5% 补差价；这笔钱不向客户收取。
- 补差价不写入原订单收款、代理佣金、采购余额或每日核算单。
- 平台只做人工开票，不对接自动开票服务，也不自动向任何人打款。

## 状态流程

1. 代理商在已付款订单详情填写公司名称、税号、发票金额、收票邮箱、联系人及备注。
2. 系统生成独立补差价支付单，按钮名称为“支付提交”。
3. 支付宝商品说明固定为“订单补差价”，不显示“开票费用”。
4. 只有支付宝异步通知验签或官方订单查询确认金额、应用和收款方完全一致后，申请才从“待付补差”变成“已提交”。
5. 管理员在“发票管理”或首页“待开票”进入申请，先“开始处理”。
6. 资料有误时选择“退回补充资料”；代理商修改后重新提交，不重复付款。
7. 管理员人工开具发票后填写发票号码和发送说明，状态变为“已开票”。

## 资金与审计

每份申请保存关联订单、发票金额、5%补差金额、支付宝流水、付款时间、公司名称、加密税号、处理说明、发票号码和操作版本。补差价支付采用独立 `invpay_` 单号，不能与客户订单支付或采购钱包充值混用。同一支付宝流水不能绑定两份补差价支付单。

申请付款窗口过期时，代理商从“开票申请”重新发起支付；新支付单使用新的外部交易号，避免复用已关闭的支付宝交易。未付款申请不会进入管理员待办。

## 后台入口

- 代理商：`订单管理 → 订单详情 → 开票申请`，或侧边栏“开票申请”。
- 平台：首页“待开票”、侧边栏“发票管理”，或 `代理管理 → 开票记录`。
- 管理员只有一个处理人，不设置多人复核或自动审批。
