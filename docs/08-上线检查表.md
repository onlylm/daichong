# 上线检查表

版本：v0.2。每项填写负责人、完成时间与证据链接；任何 P0 未完成均不得生产上线。`merchant_id` 为代理商租户技术字段，不代表支付宝商户。

## P0 架构与隔离

- [ ] 使用全新域名、服务器/VPC、PostgreSQL、Redis、KMS 和密钥，未共享旧生产数据或秘密。
- [ ] 所有租户表有 `merchant_id`，唯一键/外键含租户维度。
- [ ] API 数据库角色无 `BYPASSRLS`，RLS 在预生产实际启用。
- [ ] 订单、退款、台账、结算、Webhook 的跨租户测试全部通过。
- [ ] 平台成本与 Quefa 支付配置在代理商 API、导出、日志和错误中均不可见。

## P0 API 与密钥

- [ ] HMAC 规范串与 Node/PHP/Python 示例互相验证。
- [ ] 时钟偏差、Nonce 重放、签名比较、IP/CIDR 白名单已测试。
- [ ] POST 等变更请求强制幂等键，同键异请求冲突已测试。
- [ ] 密钥一次显示、双钥轮换、吊销、过期和审计已验证。
- [ ] NTP、TLS、WAF、速率限制和请求大小限制已启用。

## P0 支付、履约与退款

- [ ] 仅存在 Quefa 平台级支付宝配置；代理商表、后台和开放 API 均无支付账号/应用/私钥/证书配置入口。
- [ ] Quefa 自有支付宝异步通知验签后主动查单；订单号、金额、Quefa 收款主体全部核对。
- [ ] 浏览器同步跳转不能改变支付状态。
- [ ] 履约结果未知只查询不重复提交；Worker 租约恢复已测试。
- [ ] Session AES-GCM 信封加密、AAD 绑定、终态清理和日志脱敏已验证。
- [ ] 充值供应 API Key、Webhook Secret 和直充内部资源引用只写并加密保存，管理响应、日志、错误和导出均不回显。
- [ ] 供应基础地址只允许 HTTPS 精确域名白名单，已验证内网 IP、用户信息、非标准端口和非允许主机均被拒绝。
- [ ] 平台只实现余额、套餐、直充、CDK、回调和对账；代理商与平台接口均不存在虚拟支付工具创建、敏感资料查询、余额操作、退款、冻结或删除能力。
- [ ] 客户只在 Quefa 页面提交凭据；代理商页面、API、Webhook、日志均不出现供应商域名、订单号或原始 CDK。
- [ ] direct 预检/下单/轮询和结果未知恢复已使用供应方沙箱真实验证。
- [ ] 代理品牌公开号的一次性兑换、并发占用、失败释放、成功清除底层码和签发退避已验证。
- [ ] 供应回调使用原始请求体验签、稳定事件 ID 持久化去重，并能处理乱序与重复事件。
- [ ] 退款申请先锁额度/履约，审核与实际出款分离。
- [ ] 普通退款、补差退款、失败、未知结果和重复请求已测试。

## P0 财务

- [ ] 135/110/10 示例中，买家向 Quefa 支付 135 元，最终代理商差价为 15 元。
- [ ] 用户付款、渠道实收、供货价、普通退款、补差、待结算、手续费、上游成本和 Quefa 毛利可分别核对。
- [ ] 所有分录借贷平衡，可从分录重建余额。
- [ ] 已封存结算不可修改，结算后退款生成下一期负向调整。
- [ ] 支付渠道和上游成本每日对账，差异有工单、负责人和 SLA。

## P0 运维与安全

- [ ] 生产 Secret 仅由 Secret Manager/KMS 注入，仓库/镜像/日志扫描无秘密。
- [ ] 充值供应管理域名仅在内网/VPN 可达，平台管理员启用 MFA/RBAC；过渡期管理令牌已轮换且受 IP 白名单保护。
- [ ] 数据库与 Redis 私网访问、TLS、最小权限和审计已配置。
- [ ] 备份加密、PITR、保留策略已启用，完成隔离恢复演练并达到 RPO/RTO。
- [ ] API/Worker 健康检查、优雅停止、告警、仪表盘和死信处理已验证。
- [ ] 依赖、镜像、SAST/DAST、渗透测试高危问题已关闭。

## 联调与业务准备

- [ ] 每个代理商合同、商品授权、供货价、销售上限、结算周期和退款承担规则已复核。
- [ ] 代理商出口 IP、Webhook URL、联系人与紧急停用流程已登记。
- [ ] 沙箱完成签名、开单、支付、direct、QF CDK、退款、补差、结算、Webhook 和跨租户验收。
- [ ] Quefa 自有支付宝新系统专用应用/商户配置和上游新账号均已隔离；代理商未提供且无法配置支付凭证。
- [ ] 客服失败码话术、退款审核 SOP、财务对账 SOP、事故响应通讯录已完成。

## 灰度与回滚

- [ ] 首批代理商、商品、日金额/日订单限额和观察期已批准。
- [ ] 灰度看板覆盖支付成功率、履约失败率、退款、Outbox、差异和负结算余额。
- [ ] 回滚镜像、向前修复迁移、停用 Worker 与密钥吊销流程已演练。
- [ ] 未获书面授权不执行真实支付、退款、迁移或生产部署。
