# 上线检查表

更新时间：2026-10-02。适用范围：单服务器 SQLite WAL 首发候选。当前为验收准备，**不是发布许可**；本轮不部署、不接入实单、不操作生产资金。

首发只收口自动充值、业务追溯、资金与充值防重，以及一个平台管理员可完成的日常运营。业务验收矩阵与剩余事项统一见 [100-首发候选验收清单](100-首发候选验收清单.md)。每项填写候选 SHA、环境、操作者、时间、结果和脱敏证据；未执行不得勾选。

## 当前架构与资金口径

- API 与 Worker 使用同一 SQLite WAL 持久化文件，按当前单机、低订单量范围验收。PostgreSQL/RLS 是未来多节点迁移事项，不能用它们的脚本或恢复结果证明 SQLite 主账本已验收，也不要求本轮新增迁移模块。
- `merchant_id` 是代理商租户技术字段，不是支付宝商户。隔离效果以当前鉴权、查询、事务与跨租户测试验证。
- 新交易仅四款 GPT 套餐与支付宝；平台不保存代理商支付私钥。客户可以使用 Quefa 托管页或既有代理自建兑换入口，对外结果不泄露底层供应信息。
- 销售 135 元、供货 110 元，另退差价 10 元时，代理佣金仍为 **25 元**。若是普通客户退款 10 元，示例佣金才是 15 元。退差、真实成本和普通退款分别记录。
- 可信收款与成功履约触发佣金一次性入账；北京时间 22:00 核算全部合格历史未核算订单。生成核算单不出款，管理员实际外部付款后登记凭证，再另行核销；不要求第二名管理员。
- 退款审核可能调用支付宝退款接口。每日核算、提现的“登记外部付款”才是凭证补记，不能把所有财务按钮视为没有出款副作用。
