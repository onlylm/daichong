# 工单分页索引与隔离并发压测

日期：2026-10-02。仅在本地临时 SQLite 数据库验证，未部署生产。

平台工单列表同时排除归档、系统异常、API 申请、等级申请和提现申请。原通用索引不能覆盖这一组 JSON 筛选条件；新增复合索引覆盖筛选、更新时间和 ID 排序。查询计划测试确认全平台工单计数使用覆盖索引、分页读取使用同一索引。代理租户查询仍保留原租户索引路径。

执行 `npm run bench:pagination`：每类历史记录分别为 100、1,000、5,000 条，页面大小 20，混合 40 个并发注入请求。各档均未调用全量列表；5,000 条档共 76 次数据库查询，响应 P95 为 485.05 毫秒，低于脚本的 500 毫秒目标。改动前同机一次结果为 491.32 毫秒；差异较小，不能据此推断线上端到端延迟或稳定收益。

此压测通过 Fastify `inject` 在单进程本地执行，不包含公网、浏览器渲染、生产数据分布及多进程写入竞争。真实生产快照的隔离迁移和性能演练、用户端卡顿验收仍待完成；上线前不得把本结果标为生产性能验收通过。
