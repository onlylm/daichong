# 退款差异资金出口保护

## 背景

支付宝渠道累计退款金额高于本地已准确分类入账金额时，系统会建立独立的 `refund_reconciliation` 财务差异记录。该记录不是售后工单，也不能仅用于限制新的充值提交。

## 本次收口

- 代理收益划转前检查：只要已释放收益的订单仍有正数退款差异，拒绝划转。
- 提现申请、提现审核和确认打款前执行同一检查，防止差异核实期间转出原佣金。
- 每日核算确认打款只检查本核算单包含的订单，关联退款差异未解决时拒绝登记付款。
- 未产生已释放收益的订单不会冻结钱包；其他订单的退款差异不会误伤当前核算单。
- SQLite 提供数据库侧存在性查询，避免为执行守卫而全量读取历史收益和差异记录。

## 解除条件

只有财务差异记录转为 `resolved` 且 `differenceMinor` 归零后，相关资金出口才恢复。系统不会根据金额猜测退款类型，也不会通过关闭工单解除资金保护。

## 验证

- 内存仓储：收益划转、提现申请、提现确认打款均被差异记录拦截。
- 每日核算：关联订单被拦截，无关订单不影响当前核算单。
- SQLite：数据库侧守卫能识别待核差异，解决后恢复确认打款。
