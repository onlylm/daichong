# 提现独立待办与资金处理说明

## 目标

提现属于资金业务，不再通过售后工单驱动状态或处理流程。平台管理员在“资金管理 → 提现审核”统一查看和操作全部代理商提现，首页仅聚合待办并跳转到该资金入口。

## 业务规则

1. 代理商提交提现后，申请金额从收益可用转入提现冻结。
2. “审核通过”只改变申请状态，不会自动打款，也不会扣减冻结资金。
3. 管理员完成真实线下打款后，必须填写唯一付款流水并确认，系统才扣减提现冻结。
4. 驳回申请时，冻结金额解冻回收益可用。
5. 新提现申请只创建 `wallet_withdrawal` 资金记录，不创建售后工单。
6. 历史提现工单不会删除。若历史工单已经关联提现申请，后续审核仍同步其状态，保留既有消息和审计追溯。

## 页面与接口

- 全局资金入口：`资金管理 → 提现审核`
- 全局列表接口：`GET /workspace/api/withdrawals`
- 代理商个人记录：`资金钱包 → 提现申请`
- 提交申请：`POST /workspace/api/wallets/:merchantId/withdrawals`
- 审核/确认打款/驳回：`POST /workspace/api/withdrawals/:id/review`

全局列表支持待处理、待审核、待打款、已打款、已驳回和全部状态。待处理记录按申请时间从旧到新排列，优先处理等待最久的申请。

## 回归验证

- 提交新提现只产生资金申请，不产生售后工单。
- 首页待办返回全局待处理提现数量和具体记录。
- 全局列表支持分页及代理商名称、编号、收款信息、状态和付款流水展示。
- 代理端提交成功提示指向资金钱包，不再提示在工单跟踪。
