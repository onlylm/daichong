# 支付终态旧付款码失效说明

订单、采购余额充值和开票补差支付进入已付款、已退款、已关闭或已过期状态后，状态接口不再返回此前生成的支付宝付款码和二维码图片。浏览器收到状态变化时会同时清空已经显示的旧二维码与跳转地址。

该处理不删除原支付记录，后台仍可按原订单和支付流水追溯交易；只是禁止终态订单继续向付款人展示可扫码入口。订单支付结果仍以支付宝验签通知和主动查询结果为准。

覆盖的回归场景：

- 待付款有效期内可以显示已生成的付款码；
- 支付宝明确关闭交易后，旧付款码立即从状态响应中移除；
- 本地付款窗口到期后，即使支付记录仍保存旧码，也不再返回；
- 前端轮询发现状态变化时清空已经绘制的二维码和链接；
- 代理后端直出付款码接口继续拒绝已付款、已关闭、已退款和已过期订单。
