# 开放平台工单与钱包分页

## 修复内容

代理商无需自建网站，也可以直接在 Quefa 工作台下单、充值、查看工单和资金。若代理商选择 API 对接，同一套服务端数据仍通过开放接口提供。

旧 `GET /v1/tickets` 会返回代理全部历史工单，旧 `GET /v1/wallet` 会返回代理全部钱包流水。现已改为：

- `GET /v1/tickets?status=&page=&limit=`：状态在数据库分页前筛选，默认 50 条、最大 100 条，响应为 `data + meta`；
- `GET /v1/wallet?page=&limit=`：`data` 仍为双钱包余额，`entries` 为当前页流水，`entries_meta` 为分页信息，默认 50 条、最大 100 条；
- 工单内部备注仍不对代理开放；钱包接口仍为只读，不能增加余额、审核或确认打款；
- 工作台已有的工单和钱包分页路径不变。

## 验证

签名 API 集成测试创建多页工单与钱包流水，验证第二页数量、全量总数、页数和租户范围正确，并确认 SQLite 未调用工单或钱包流水全量列表方法。

本地分支尚未部署生产。代理商接入方应读取分页元数据并提供翻页或增量同步，不能假设一次请求包含全部历史。
