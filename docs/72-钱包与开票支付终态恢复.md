# 钱包与开票支付终态恢复

采购余额充值和开票补差支付使用与订单支付一致的资金事实规则：

- 没有生成支付宝交易的支付单到期后直接标记 `expired`，停止无效渠道轮询；
- 已生成付款码时继续以支付宝查询为准，交易不存在且已过期时标记 `expired`；
- 支付宝明确返回 `TRADE_CLOSED` 时标记 `closed`；
- `expired` 可接收随后到达且验签、商户、金额、单号全部一致的成功通知；
- `closed` 是渠道明确终态，不允许用晚到成功消息直接覆盖；
- 终态写入会在事务内重读当前记录，不能覆盖并发到账结果；
- 重复成功通知复用原流水，不会重复增加采购余额或重复提交开票申请。

开票补差支付单的复用、过期和新建操作也在同一数据库事务中完成，避免多进程并发时用旧的过期快照覆盖已支付记录。
