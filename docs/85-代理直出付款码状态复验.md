# 代理直出付款码状态复验

## 规则

幂等响应只能复用“生成付款码”这一外部写入结果，不能冻结订单的业务状态。每次返回付款码前都必须依据当前状态重新判断是否可支付。

## 检查时点

- 首次请求、调用支付宝前：检查代理开关、订单归属、平台收款渠道、金额、有效期和支付状态。
- 支付宝接口返回后：重新读取订单与支付记录。若通知已经先到、订单已付款、订单已过期或绑定变化，不保存也不返回新码。
- 相同幂等键重放：在返回历史响应前再次检查当前开关、付款状态、有效期和绑定关系；历史成功响应不能绕过当前限制。

## 并发结果

支付通知先于取码接口返回时，付款事实优先。取码接口返回 `payment_not_available`，释放未完成的幂等占位，并清理付款码生成租约，不把过时二维码写入支付记录。

## 兼容性

接口字段和旧 `qr_payload` 含义不变；只有原本不应再使用的历史二维码会被拒绝。
