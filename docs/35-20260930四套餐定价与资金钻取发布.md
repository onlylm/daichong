## 本批功能

- 订单列表 SQL 分页，资金流水 SQL 分页与余额聚合；平台订单、资金查询包含停用代理商的历史记录。
- 异常任务分批扫描，有持久化游标；站内异常工单支持处理超时升级及业务恢复后转已解决，不调用 SMTP。
- 今日资金卡片、近 7 日汇总可点击打开分页明细，再进入订单详情；区分分佣计算额与已入账收益。
- 资金卡片仍按订单付款日统计其当前收退款状态，不是支付宝账单对账或退款发生日现金流。净收款不是毛利，尚未减手续费。
- 退差核算不自动出款、不重算历史订单、不改分佣。仍须防止普通退款、旧差价退款、补差付款重复执行。
- 开放文档收敛四款，保留代理自有品牌前端、CDK 自动代充和失败后原入口重提约定。
