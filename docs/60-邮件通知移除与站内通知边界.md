# 邮件通知移除与站内通知边界

## 当前规则

- 平台面向代理商运营，不向终端客户发送业务邮件。
- 充值、CDK、退款等异常统一进入站内待办与工单。
- 已接入开放平台的代理商通过 Webhook 接收订单进度和最终结果。
- 未接入开放平台的代理商直接在代理工作台查看订单、待办和工单。

## 本次清理

- 删除 SMTP、邮箱偏好、邮件任务和失败重试接口。
- 删除 `nodemailer` 及其类型依赖，不再保留可被误认为有效的邮件配置入口。
- 删除邮件配置、偏好和队列的运行时类型；历史数据库中的旧记录不会再被读取或执行。
- 保留发票申请中的收件邮箱字段。该字段只用于收集电子发票交付资料，不属于通知通道。

## 运维影响

生产发布不需要配置企业邮箱、SMTP 密码或邮件队列。异常处理以站内待办为准，开放平台事件以 Webhook 投递记录为准。
