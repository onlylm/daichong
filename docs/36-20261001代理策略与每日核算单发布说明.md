## 每日核算单

系统每天北京时间 22:00 扫描截至该时点全部尚未进入有效核算单的合格历史订单，不只扫描当天订单。订单必须同时满足：平台收款、渠道确认足额支付、真实履约成功、非测试且未归档。

核算单以订单下单时冻结的供货价和平台人民币内部成本计算：

- 代理佣金：该批订单已经释放到收益钱包的金额；
- 标准毛利（历史字段 `platformProfit`）：冻结供货价减冻结标准内部成本；未扣渠道手续费、实际成本偏差、退款及其他费用，不能当作实际净利润；
- 应付金额：本批代理佣金与当前尚未被其他待付款核算单占用的收益余额两者取小；
- 同一订单不能重复进入未作废的核算单。

资金流程被严格拆成三步：

1. `pending_payment`：服务器只生成核算结果，不付款、不扣余额；
2. `paid`：管理员已经在外部渠道真实付款，填写唯一付款流水号和付款凭证说明后确认，系统才扣减对应收益余额；
3. `reconciled`：管理员另行核对代理到账、金额和流水后人工核销。

待付款单可以作废，作废不动资金，相关订单回到未核算池。系统没有自动打款动作，也不把“生成核算单”或“上传凭证”当成已经到账。

## 与参考运营手册的结合边界

采用了全历史未核算池、单据幂等、付款与核销分离、真实凭证、租户隔离和内部成本仅管理员可见等规则。未照搬参考系统的 API 头、IP 白名单和多人复核流程：本项目继续使用现有 HMAC 签名协议；平台管理员只有一人，因此资金动作由同一管理员分步骤人工确认，但不会自动出款。
