# 1 元纯支付联调

## 定位

`POST /v1/payment-tests` 创建固定人民币 1.00 元的平台收款联调订单。它用于验证签名、付款页、支付宝到账通知、查单和 Webhook，不属于四款 GPT 正式商品。

请求只接受代理订单号和已登记的可选通知地址，金额、支付方式、商品代码和履约属性均由服务端固定，不能临时覆盖。

```json
{
  "merchant_order_no": "PAYMENT-CHECK-20261001-001",
  "notify_url": "https://merchant.example.com/quefa/webhook"
}
```

## 固定边界

- 金额固定为 `1.00 CNY`。
- 仅使用平台收款，不占用采购余额。
- 订单标记为 `purpose=payment_test`，不计代理佣金、每日核算或商品成本。
- 不生成 CDK，不开放充值资料入口，不创建履约任务。
- CDK Worker、充值 Worker 和所有上游接口均硬性排除该订单。
- 付款成功只说明支付链路联调完成，不代表任何 GPT 商品购买或充值权益。

支付测试仍使用普通订单查询和支付 Webhook，因此代理可用它完成上线前的支付闭环验收，而不触发上游采购。
